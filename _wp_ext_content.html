Sau khi download về bạn sẽ có file : printuz_etxension_v1.3.zip, hãy mở lên và thực hiện các thao tác sau:

  1. Extract To : giải nén về thư mục
  2. Sau khi chọn nơi giải nén về thì bạn bấm OK
  3. Mở tiện ích trong trình duyệt Google Chrome.
  4. Quản lý tiện ích
  5. Bật chế độ dành cho nhà phát triển
  6. Tải tiện ích đã giải nén
  7. Tìm tới vị trí bạn đã giải nén folder ở bước 2,chọn folder : printuz_etxension_v1.3
  8. Select Folder
  9. Login vào https://app.printuz.com/ , phí trên cùng bên phải hãy vào Profile
  10. Copy token : Mỗi User sẽ có 1 token riêng để bỏ vào extension.
  11. Vào tiện ích trên Chrome, sau đó chọn Printuz.
  12. Paste Token của abjn vào sau đó nhấn Add token.
  13. Mở 1 link sản phẩm bất kỳ , bạn sẽ tháy nút add product hiện trên extension Printuz. Khi bạn bấm Add Product, thì mọi thông tin như tittle , Hình ảnh , Item ID sẽ tự động save về My Product trên App Printuz của bạn.
  14. Vào My product chọn sản phẩm vừa add, có thể chọn nhiều sản phẩm cùng lúc.
  15. Chọn Product
  16. Change Product – chỉ khi bạn add sản phẩm vào đúng loại Product thì khi Fulfill mới upload được file Design.

Với bản V1.3 thì hiện nay bạn đã chỉ save được sản phẩm từ Ebay, Etsy và Amazon về cho các bạn thôi, chúng tôi đang phát triển thêm vào thời gian tới.

WORKFLOW:

  1. Người dùng nhập token seller HDgangz => chọn store muốn kết nối => lưu setting.
  2. Đi vào 1 order => Bấm “GET ORDER INFO” => Extension lấy thông tin và hiển thị => người dùng có thể check lại thông tin => chỉnh sửa nếu cần => bấm “SYNC & AVE ORDER #XXXXXX”.
  • Nếu thành công Extension sẽ lưu order đó vào history và trả lại nút “GET ORDER INFO”, người dùng có thể sang trang order khác và thực hiện tương tự.
  • Nếu fail (order không lưu history, không gửi đi) check lại token hoặc báo lỗi kỹ thuật.
    3 History lưu trữ toàn bộ các order đã gửi về HDgangz (max 1000 đơn).
    Ở múc history có 2 tính năng chính:
  • Xuất file CSV nếu cần backup dữ liệu lưu trữ: chọn order cần xuất => chọn Exprt CSV => Tool sẽ tải về thư mục download mặc định.
  • Re-sync, người dùng có thể gửi lại order nếu bị xóa: chọn tích chọn order cần gửi lại hoặc chọn select All để chọn tất cả => bấm “RE-SYNC SELECTES ORDERS (X)” => Tool sẽ hỏi
  • Nếu bâm nhầm ẩn Cancel.
  • Nếu dúng bấm Yes, Sync.
